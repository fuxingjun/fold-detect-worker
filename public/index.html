GET /api/health

健康检查

查看最近同步的机型数量与时间

返回: ok, lastSyncCount, lastSyncAt

GET /api/fold-models

关键词筛选

按关键词匹配折叠屏机型, 不传则使用内置默认关键词

参数说明
keywords可选, 逗号分隔, 如 Mate X,Magic V

返回: keywords, total, data[]

GET /api/fold-models/verify

打分判定

test-model 打分策略识别横向大折机型, 输出置信度与理由

参数说明
min可选, 1|true|yes 时仅返回精简字段

返回: strategy, total, data[]

GET /api/fold-models/download

数据下载

下载折叠屏机型 JSON 文件 (fold-models.min.json 同构, 动态生成)

返回: JSON 文件: model, brand, modelName

GET /api/models

机型查询

按品牌/型号精确或模糊匹配查询全量机型数据

参数说明
brand品牌, 如 华为
model型号, 如 Mate X5
brand_matchfuzzy|exact, 默认 fuzzy
model_matchfuzzy|exact, 默认 fuzzy
limit返回条数上限, 默认 100, 最大 500

返回: query, total, data[]

POST /api/sync

手动同步

触发一次数据同步; 配置 SYNC_TOKEN 时需请求头 x-sync-token

参数说明
x-sync-token请求头, 鉴权令牌

返回: ok, synced, skipped, changed

数据来源: MobileModels-csv · 同步完成后通过企业微信机器人推送变更通知
